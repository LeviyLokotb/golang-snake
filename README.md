# 🐍 Змейка на Go 🍎
- Рассчитана на терминал Linux (используются ANSI последовательности)
- Рабочая версия, постепенно добавляю фичи
- Только стандартные библиотеки

# 📦 Установка
Позже добавлю нормальный скрипт установки

- Клонируйте репозиторий:  
```bash
git clone https://github.com/LeviyLokotb/golang-snake.git && cd golang-snake
```
- Создайте конфиг
```bash
mkdir -p ~/.config/snake-go
cp snake_config.json ~/.config/snake-go/config
```
- Соберите исполняемый файл
```bash
go build -o snake-go ./cmd/snake/main.go 
```
- Переместите в директорию, которая есть в $PATH
```bash
mv snake-go ~/.local/bin/
```
- Удалите исходники (по желанию)
```
cd .. && rm -rf golang-snake
```
- Готово

# ⛳ Запуск
- Без сборки:
```bash
go run ./cmd/snake/main.go 
```
- С указанием другого файла конфига:
```
snake-go --config "path/to/config.json"
```

# 🎮 Управление
- стрелочки либо `wasd` либо `khjl` -- поворот
- `q` либо `~` -- выход
- `return` либо `r` -- с начала
- `space` либо `p` либо `e` -- пауза
- Работает в том числе с русской раскладкой

# ⚙️ Конфигурация
В файле конфига можно менять: 
- Высоту (`width`) и ширину (`height`) поля (в символах)
- Задержку между кадрами (`delay`)
- Стартовую длину змейки (`initSnakeLength`)
- Текстуры (символы)
  - При указании нескольких будут выбираться случайно
  - Будьте внимательны к ширине символов: эиодзи обычно шире (добавьте один пробел к текстовым символам, в том числе к фону)
- Эффекты текстур
  - Некоторые цвета можно указать словами
  - Можно указать произвольный цвет в RGB палитре (в виде `#FFFFFF`)
  - Если нужно совместить (например с жирным выделением), укажите через `+` в любом порядке (`RED+BOLD`)
  - Список предопределённых эффектов:
  ```
  RESET
  BOLD
  BLINK
  FAST_BLINK
  NEGATIVE
  BACKGROUND
  BLACK
  RED
  GREEN
  YELLOW
  BLUE
  MAGENTA
  CYAN
  WHITE
  ```
- `pulsarMode`: при `true` текстуры будут меняться случайно каждый кадр
